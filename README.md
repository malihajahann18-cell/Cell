# Cell Odyssey: Journey Inside a Cell

A 3D interactive cell explorer built with HTML, CSS, Tailwind CSS (CDN) and JavaScript (Three.js via CDN).

## How to run
Keep `index.html`, `style.css` and `script.js` in the same folder and open `index.html` in a browser (internet needed for the CDN libraries).

## Features
- 3D cell with nucleus, mitochondria (full structure with labelled parts), Golgi, ER and ribosomes
- Drag to rotate, pinch or scroll to zoom, tap an organelle or a button to fly to it
- "What it does / does not do" info for each organelle
- Mission mode: follow a protein from the nucleus to outside the cell
- Quiz with timer and score
- Animal / plant cell toggle (cell wall, chloroplasts, central vacuole)
- Optional sound effects and ambient hum
